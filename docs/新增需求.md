# 新增需求：Vue 监控 SDK 实例化接入

适用范围：`@weils-monitor/vue` 和 `example/vue`。通过 `createMonitor` 在独立配置文件中创建监控实例，再将该实例安装到 Vue 应用。实例既能启动全部采集器，也能按需启动指定采集器，并支持通过 HTML 属性自定义点击事件的 `action`。

## 1. 在配置文件中创建实例

`createMonitor(options)` 接收 SDK 配置，返回可传给 `app.use()` 的 `monitor` 实例。业务代码可以从同一个配置文件导入它。

```ts
// src/config/monitor.ts
import { createMonitor } from '@weils-monitor/vue'

export const monitor = createMonitor({
  url: '/api/v1/monitor',
  projectName: 'weils-monitor-example',
  appId: 'vue-example',
  userId: 'visitor',
  isImageUpload: false,
  batchSize: 20,
  maxBatchBytes: 50 * 1024,
  sampleRate: 1,
  replay: {
    enabled: import.meta.env.VITE_MONITOR_REPLAY !== 'false',
    url: '/api/v1/records',
    sampleRate: 1,
    beforeErrorMs: 10_000,
    afterErrorMs: 5_000,
    blockSelector: '.reports-panel',
    onStatus: status => console.info('[replay]', status),
  },
  debug: false,
})

monitor.addClickHandler('mask-close')
  .addClickHandler('mask-open')
  .addClickHandler('custom-data')
```

`url` 和 `appId` 是必填配置。`projectName` 会写入批量上报包和每条事件。`batchSize` 默认 20，`maxBatchBytes` 默认 50 KB。`sampleRate` 会写入批量上报包的 `sample_rate` 字段；当前实现不会据此随机丢弃事件。`resourceDurationThreshold` 默认 100（毫秒），用于过滤 `metric_name: "resource"` 事件：只有耗时达到该值的资源才上报，设为 `0` 表示不过滤。`debug: true` 会在事件入队时打印日志；无论 `debug` 是否开启，SDK 都会派发 `weils-monitor:report` 浏览器事件。当前 SDK 使用页面级共享配置，建议同一页面只创建一个监控实例。

## 2. 安装并启动监听

`app.use(monitor)` 安装 Vue 错误处理器，并保留应用先前设置的 `app.config.errorHandler`。调用 `monitor.observer()` 才会启动全部采集器。示例在页面挂载后启动，以便演示面板先订阅上报事件。

```ts
// src/main.ts
import { createApp } from 'vue'
import App from './App.vue'
import { monitor } from './config/monitor'

const app = createApp(App)
app.use(monitor)
app.mount('#app')

monitor.observer()
```

`observer()` 启动以下采集能力：

| 类别 | 采集器 |
| --- | --- |
| 错误 | `error.error()` |
| 行为 | `behavior.click()`、`behavior.pageChange()`、`behavior.pv()` |
| 性能 | `observerEntries()`、`observerFP()`、`observerFCP()`、`observerLCP()`、`observerLoad()`、`observerCLS()`、`observerFID()`、`observerINP()`、`observeTTFB()`、`observerLongTask()` |
| 稳定性 | `stability.observerBlankScreen()` |

如只需部分能力，安装后调用对应方法即可：

```ts
const { error, behavior, performance, stability } = monitor

error.error()
behavior.click()
behavior.pageChange()
performance.observerINP()
performance.observeTTFB()
stability.observerBlankScreen()
```

同一实例上的采集器重复启动时只执行一次；可先按需启动，再调用 `monitor.observer()` 补齐其余采集器。`app.use(monitor)` 本身不启动这些采集器。

## 3. 自定义点击 action

`addClickHandler(attributeName)` 注册一个 HTML 属性名，并返回同一个实例以支持链式调用。它注册的是属性名，`action` 取自元素上的属性值；`event_type` 始终为 `behavior`。这是普通 HTML 属性，不需要注册 Vue 指令。

```vue
<template>
  <button mask-close="关闭遮罩">关闭</button>
  <button mask-open="打开遮罩">打开</button>
  <button custom-data="自定义上报数据">上报</button>
</template>
```

启动 `behavior.click()` 或 `monitor.observer()` 后，点击第一个按钮会产生如下事件字段；公共字段由 SDK 自动补充：

```json
{
  "event_type": "behavior",
  "action": "关闭遮罩",
  "target": {
    "selector": "… > button",
    "text": "关闭",
    "tag": "BUTTON"
  }
}
```

- 点击元素的子节点时，SDK 会向上查找已注册属性，使用最近匹配元素的属性值和目标信息。
- 没有找到非空的已注册属性值时，仍按普通点击上报：`event_type: "behavior"`、`action: "click"`。`target.selector` 的实际值取决于元素在页面中的位置。
- 属性名会去除首尾空格并转为小写；空属性名会抛出错误。同一属性重复注册不会重复上报。

## 4. 错误录制与上传

以上配置与当前 Vue 示例一致：默认开启 Replay，设置 `VITE_MONITOR_REPLAY=false` 后重启可关闭。通用 SDK 不配置 `replay.enabled` 时仍默认关闭，默认窗口为前 30 秒、后 10 秒，示例显式缩短为前 10 秒、后 5 秒。

开启 Replay 后异步录制，JS、Promise 与 Vue 组件错误经普通采集器上报后自动触发错误窗口；仅点击页面不会上传。约 5 秒后片段上传到 `/api/v1/records`，Vite 转发到 `localhost:8888`。`[replay] uploaded` 表示所有分片回执已校验成功。示例只录制与上传，查看回放使用同级 `monitor-frontend`。

`monitor.replay.flush()` 不截断当前错误窗口；`stop()` 才会提前封存已触发片段。完整接口及排障见 [Replay 接入与排障](replay.md)。

## 5. 协议与验收

自定义点击使用 `event_type: "behavior"`，并将属性值写入 `action`，符合[上报字段协议](./字段要求.md)中行为事件的字段约定。

验收时应确认：

1. 独立配置文件导出的 `monitor` 能通过 `app.use(monitor)` 安装，且原有 Vue 错误处理器仍会被调用。
2. `monitor.observer()` 能启动全部采集器；按需调用可只启动指定采集器；重复调用不产生同一采集器的重复监听。
3. 点击普通元素上报 `event_type: "behavior"`、`action: "click"`；点击三个示例按钮时 `event_type` 仍为 `behavior`，`action` 分别为 `关闭遮罩`、`打开遮罩`、`自定义上报数据`，点击按钮内的子元素也能匹配。
4. `debug: false` 时仍可收到 `weils-monitor:report` 事件，`debug: true` 时还会输出控制台日志。
5. 未设置录制环境变量时，示例默认输出 `started`；触发受支持错误并等待约 5 秒后发送 `/api/v1/records`，成功后输出 `uploaded`；普通点击及资源错误不生成上传片段。

可运行示例位于 `example/vue/src/config/monitor.ts`、`example/vue/src/main.ts` 和 `example/vue/src/App.vue`。
