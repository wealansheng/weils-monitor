# 前端监控上报字段协议

本文定义 `POST /api/v1/monitor` 接收的 JSON 事件格式。数据库字段与存储策略见 [ClickHouse 前端监控模型](clickhouse-schema.md)。

## 请求约定

- `Content-Type`：建议使用 `application/json`。
- 默认请求体上限：5 MB，可通过 `MAX_BODY_SIZE` 调整。
- 请求体必须是 JSON 对象，不接受顶层数组或纯文本。
- SDK 推荐使用批量事件包上传；`events` 是事件对象数组，每个事件仍须满足下文的公共字段和专用字段要求。
- 字段名默认使用 snake_case。资源性能字段兼容浏览器 Performance API 常见的 `initiatorType`、`transferSize`、`encodedBodySize`、`startTime`。
- 所有耗时字段单位均为毫秒，大小字段单位均为字节，除非字段说明另有约定。

### SDK 批量事件包

```json
{
  "app_id": "web-portal",
  "projectName": "web-portal",
  "sdk_version": "1.0.1",
  "send_time": 1712345679000,
  "sample_rate": 1,
  "events": [
    {
      "event_id": "8a604b37-b7c8-4f26-9eeb-37d38b2d55f3",
      "event_type": "behavior",
      "timestamp": 1712345678901,
      "app_id": "web-portal",
      "projectName": "web-portal",
      "action": "page_view"
    }
  ]
}
```

SDK 满足以下任一条件时发送当前队列：事件数达到配置阈值（默认 20）、序列化体积达到配置阈值（默认 50KB）、页面进入隐藏或卸载状态，或采集到严重错误。`send_time` 是批量包实际发送时的 Unix 毫秒时间戳，`sample_rate` 取值范围为 0 到 1。

## 公共字段

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `event_id` | UUID 字符串 | 是 | `8a604b37-b7c8-4f26-9eeb-37d38b2d55f3` | 事件唯一 ID；重试必须复用同一个 ID |
| `event_type` | 字符串 | 是 | `error` | `performance`、`request`、`resource`、`error`、`stability`、`behavior` |
| `timestamp` | 正整数 | 是 | `1712345678901` | 事件发生时间，Unix 毫秒时间戳 |
| `app_id` | 字符串 | 是 | `web-portal` | 应用标识；兼容输入别名 `app_key` |
| `projectName` | 字符串 | 否 | `web-portal` | 初始化配置中的项目名；批量包和每条事件均携带，字段名保持 camelCase |
| `release` | 字符串 | 否 | `1.2.3` | 发布版本 |
| `environment` | 字符串 | 否 | `production` | 默认 `production` |
| `user_id` | 字符串 | 否 | `u_12345` | 必须脱敏，不应使用邮箱、手机号等明文信息 |
| `session_id` | 字符串 | 否 | `s_abc` | 会话标识 |
| `page_url` | 字符串 | 否 | `https://example.com/home?tab=1` | 完整页面 URL，敏感查询参数需移除 |
| `route` | 字符串 | 否 | `/home` | 路由路径 |
| `referrer` | 字符串 | 否 | `https://google.com` | 来源页 |
| `device` | 对象 | 否 | `{"type":"mobile","model":"iPhone 14"}` | 设备类型和型号 |
| `browser` | 对象 | 否 | `{"name":"Chrome","version":"120"}` | 浏览器名称和版本 |
| `os` | 对象 | 否 | `{"name":"iOS","version":"17"}` | 操作系统名称和版本 |
| `network` | 字符串 | 否 | `4g` | 网络类型，如 `wifi`、`4g` |
| `locale` | 字符串 | 否 | `zh-CN` | 语言地区 |
| `screen` | 字符串 | 否 | `390x844` | 屏幕分辨率 |
| `viewport` | 字符串 | 否 | `390x700` | 视口大小 |
| `sdk_version` | 字符串 | 否 | `1.0.0` | SDK 版本 |
| `trace_id` | 字符串 | 否 | `trace_abc` | 链路追踪 ID |

以下示例省略了部分可选公共字段，但每次真实上报都必须包含四个公共必填字段。

## 错误事件

错误事件使用 `event_type: "error"`，并要求 `error_type`。

### JavaScript 运行时错误

```json
{
  "event_id": "8a604b37-b7c8-4f26-9eeb-37d38b2d55f3",
  "event_type": "error",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "error_type": "js_error",
  "message": "Cannot read properties of undefined",
  "name": "TypeError",
  "stack": "TypeError: ...\n    at ...",
  "filename": "https://example.com/js/app.123.js",
  "lineno": 123,
  "colno": 45,
  "component": "UserList",
  "route": "/users",
  "breadcrumbs": [
    {
      "type": "click",
      "message": "点击了刷新按钮",
      "timestamp": 1712345678000
    }
  ],
  "tags": {
    "module": "user"
  },
  "extra": {
    "userId": "u_123"
  }
}
```

### 其他错误类型

| `error_type` | 推荐字段 | 说明 |
| --- | --- | --- |
| `promise_error` | `reason`、`stack` | 未捕获 Promise 异常 |
| `resource_error` | `resource_url`、`resource_type`、`tag_name` | 图片、脚本、样式等资源加载失败 |
| `http_error` | `url`、`method`、`status_code`、`response_body`、`duration` | 接口请求失败 |
| `framework_error` | `message`、`stack`、`component`、`component_stack`、`props` | Vue、React 等框架错误 |
| `nuxt_error` | `message`、`stack`、`status_code`、`tags.status_message` | Nuxt `app:error`：`createError`、`useAsyncData`/`useFetch`、中间件、插件与挂载错误 |
| `nuxt_chunk_error` | `message`、`stack`、`resource_url`、`resource_type` | Nuxt `app:chunkError`：动态导入的分块加载失败，`resource_type` 为 `chunk` |
| `nuxt_ssr_error` | `message`、`stack`、`status_code` | 服务端渲染失败，由客户端启动时从 payload 补报 |
| 自定义值 | `message`、`stack`、`fingerprint`、`tags`、`extra` | 自定义业务错误 |

`breadcrumbs`、`extra`、`props` 可以传对象或数组，接收服务会序列化为 JSON。`tags` 的键和值应为字符串。

## 性能事件

性能事件使用 `event_type: "performance"`，并要求 `metric_name`。

### Core Web Vitals

```json
{
  "event_id": "c6347651-a42c-467c-a211-2e697927a8bc",
  "event_type": "performance",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "metric_name": "LCP",
  "value": 1800,
  "rating": "good",
  "page_url": "https://example.com/home"
}
```

`metric_name` 建议使用 `LCP`、`INP`、`CLS`、`FCP`、`TTFB`。其中 CLS 的 `value` 为无单位分数，其他指标通常为毫秒。

### 页面加载阶段

```json
{
  "event_id": "f9b86033-c209-44bd-b299-a4ce51a0efac",
  "event_type": "performance",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "metric_name": "navigation",
  "dns": 20,
  "tcp": 30,
  "ssl": 40,
  "request": 100,
  "response": 200,
  "dom_ready": 800,
  "load": 1500
}
```

### 资源性能和长任务

资源性能使用 `metric_name: "resource"`，相关字段为 `name`、`initiator_type`、`duration`、`transfer_size`、`encoded_body_size`。长任务使用 `metric_name: "longtask"`，相关字段为 `duration`、`start_time`。

SDK 默认只上报 `duration` 达到 `resourceDurationThreshold`（默认 100 毫秒）的资源，以过滤缓存命中和极快请求；该配置设为 `0` 时全量上报。

### Nuxt 框架指标

`@weils-monitor/nuxt` 额外上报以下性能指标，字段沿用性能事件约定（`value`、`duration`、`start_time`、`rating`）：

| `metric_name` | 说明 |
| --- | --- |
| `nuxt_hydration` | `app:beforeMount` 到 `app:mounted` 的耗时，即 Vue 对服务端 HTML 的水合耗时 |
| `nuxt_hydration_complete` | `app:beforeMount` 到 `app:suspense:resolve` 的耗时，额外包含 Suspense 与异步数据就绪 |
| `nuxt_ssr_render` | 服务端渲染耗时；服务端写入 `Server-Timing: nuxt_ssr;dur=<毫秒>`，客户端读取 Navigation Timing 后上报 |

## 接口请求事件

接口请求使用 `event_type: "request"`，并要求 `url` 和 `method`。

```json
{
  "event_id": "525c7fa6-1648-40ee-8e0e-70a21266f240",
  "event_type": "request",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "url": "/api/order/create",
  "method": "POST",
  "status_code": 200,
  "duration": 350,
  "request_size": 1024,
  "response_size": 2048,
  "success": true,
  "trace_id": "trace_abc",
  "request_body": "{\"productId\":\"p_123\"}",
  "response_body": "{\"orderId\":\"o_456\"}"
}
```

生产环境默认不建议采集完整请求体和响应体。如确需采集，必须设置白名单、限制长度并移除密码、Token、Cookie 和个人信息。

## 资源加载事件

独立资源事件使用 `event_type: "resource"`，并要求 `resource_url`。

```json
{
  "event_id": "91c02692-bca6-49af-95d4-09689234c5d5",
  "event_type": "resource",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "resource_url": "https://example.com/js/vendor.js",
  "resource_type": "script",
  "duration": 450,
  "transfer_size": 204800,
  "cached": false,
  "status": 200
}
```

## 稳定性事件

稳定性事件使用 `event_type: "stability"`，并要求 `issue_type`。

```json
{
  "event_id": "1202bc61-67f0-40cc-8027-6a6d586b0ec3",
  "event_type": "stability",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "issue_type": "blank_screen",
  "blank_time": 3000,
  "root_node_count": 0,
  "page_url": "https://example.com/home"
}
```

## 行为事件

行为事件使用 `event_type: "behavior"`，并要求 `action`。

| `action` | 推荐字段 | 说明 |
| --- | --- | --- |
| `page_view` | `page_url`、`route`、`referrer` | PV / UV |
| `route_change` | `from_route`、`to_route`、`duration` | 路由跳转 |
| `click` / `exposure` | `target`、`page_url` | 点击或曝光 |
| `page_stay` | `duration`、`page_url` | 页面停留时长 |
| `nuxt_error_cleared` | `category` | Nuxt `app:error:cleared`，错误页状态被清除 |
| 自定义值 | `category`、`properties` | 自定义业务行为 |

点击事件示例：

```json
{
  "event_id": "d6dd3d25-5a95-41ba-acf5-83ac856b1125",
  "event_type": "behavior",
  "timestamp": 1712345678901,
  "app_id": "web-portal",
  "action": "click",
  "target": {
    "selector": "#submit-btn",
    "text": "提交",
    "tag": "BUTTON"
  },
  "page_url": "https://example.com/form"
}
```

自定义行为的 `properties` 可以是任意 JSON 对象。禁止在 `target.text` 或 `properties` 中采集密码、验证码、完整输入值等敏感内容。

## 成功响应

```json
{
  "ok": true,
  "eventId": "8a604b37-b7c8-4f26-9eeb-37d38b2d55f3",
  "eventType": "error",
  "bytes": 316
}
```

## 错误响应

| HTTP 状态码 | 场景 |
| --- | --- |
| `400` | 空请求、JSON 无效、公共必填字段缺失、事件专用必填字段缺失 |
| `413` | 请求体超过 `MAX_BODY_SIZE` |
| `500` | ClickHouse 写入失败或服务端内部错误 |

```json
{
  "ok": false,
  "error": "event_id must be a UUID"
}
```
